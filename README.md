# ✦ CFS - Click Super Frames - Perfect FPS - 10 Stars Edition ✦

**REAL WORKING - No fake. Loads clean, takes its time to load right.**

Click Super Frames is a micro-bugfix mod for Geometry Dash that makes your clicks feel perfect. No smoke, no fake features, just real fixes that make 60Hz feel like 240Hz.

## ✨ Real Features

- **Super Inputs - More than unlimited (20k buffer, mutex, high precision)**
  Every click is registered. No lost clicks, no ghost double-clicks, no missed inputs on spam.

- **Micro Bugfix for Clicks and GD**
  Fixes small GD bugs that make you die for no reason: stuck inputs, delayed releases, and phantom clicks on lag.

- **Slope Physics Fix**
  Fixes slope deaths and weird Y-position jumps on slopes. Your cube stays on the slope like it should.

- **【entity-CBF¦canonical_name=CBF】 Extrapolate - Visual-Only Physics**
  Visual-only extrapolation, inspired by 【entity-CBF¦canonical_name=CBF】. Smooths visuals without changing gameplay physics. Respect to syzzi & square3ang.

- **Adaptive Draw Divide - Combinable (Finally!)**
  Smart draw optimization that combines with other mods. Less lag on heavy deco levels, without breaking anything.

- **Real Hz Detector - EnumDisplaySettings**
  Detects your real monitor Hz using EnumDisplaySettings. No guessing, no fake Hz.

- **Perfect FPS - No Heavy Particles**
  Smooth FPS without heavy particles or laggy effects. Clean performance for low-end and high-end PCs.

> **60Hz feels like 240Hz.**

## 📥 How to Install

1. Download the latest `.geode` file from **Actions > Artifacts > CFS-Perfect-FPS**
2. Put the `.geode` file in your Geometry Dash mods folder
3. Open Geometry Dash
4. Go to **Geode > Mods** and check that **Click Super Frames** says `Enabled`
5. Play any level. It works automatically, no setup needed.

## ⚙️ Requirements

- Geometry Dash 2.2091
- Geode 6.0.0-alpha.1 or newer
- Windows 64-bit
